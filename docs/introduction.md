# 功能介绍


| 大任务 | 功能 | 可配置内容 |
| --- | --- | --- |
| 进入主界面 | 启动游戏，处理跳过动画、公告等进入流程 | — |
| 社团签到 | 进入社团，处理上次捐赠奖励，发起新的跑鞋请求；已有未结束请求时关闭并完成 | 短距离、英里、中距离、长距离、泥地跑鞋 |
| 团队竞技场 | 自动选择对手、确认缩短版、查看结果并循环参赛；竞技值不足时拒绝补充并结束 | 对手 1／2／3，默认 1 |
| 日常赛事安排 | 依次执行日常赛事和日常传奇赛事，自动筛选出赛角色并处理比赛结果 | 金币／协助积分；传奇赛事目标角色 |
| 限时售卖购买 | 返回主页，进入商店与限时特卖，点击全部选择并确定 | — |
| 领取奖励 | 返回主页，分别领取奖励箱和任务奖励 | 两个独立开关，默认均开启 |

### 日常赛事安排

日常赛事提供两种选择：

- **金币**：选择月光奖，按英里条件筛选出赛角色。
- **协助积分**：选择木星杯，按中距离条件筛选出赛角色。

进入日常赛事列表后先识别入场券，显示 `0/3` 时跳过这一部分，继续日常传奇赛事。

日常传奇赛事提供 **46 个角色选项**，默认神鹰，包含两个不同版本的目白麦昆。通过绿幕头像定位目标卡片，必要时结合名字或赛事文字校验；支持滑动查找，查找限时 50 秒。进入列表后显示入场券 `0/1` 时直接结束，有余票才继续。选卡后自动读取短距离、英里、中距离、长距离中的比赛类型，并按对应条件筛选出赛角色。

日常赛事、日常传奇赛事和团队竞技场的比赛结果流程均已接入限时特卖弹窗检测，出现时先取消，避免阻塞后续任务。实际购买由独立的“限时售卖购买”任务执行。

## 运行环境

| 项目 | 当前适配 |
| --- | --- |
| 系统 | Windows x64 |
| 游戏 | 简体中文界面，包名 `com.bilibili.umamusu` |
| 控制方式 | Android 模拟器，通过 ADB 连接 |
| 画面 | 竖屏 9:16，按短边 720 归一化为 720×1280 |
| 前端 | MFAAvalonia v2.15.2 |
| 框架／Agent | MaaFramework／maafw 5.12.2 |
| Python | 便携包内置 3.12；源码调试需 3.9 或以上（64 位） |

坐标针对游戏截图设置，电脑显示器的分辨率不会直接改变这些坐标。同为 9:16 的其他截图分辨率可由框架归一化；画面比例、游戏布局或语言变化时，需要重新适配。
