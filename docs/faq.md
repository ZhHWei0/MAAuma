# 常见问题


**更新项目后，MFA 仍在执行旧流程？**

便携包用户请下载新版 ZIP，解压到新目录并从新版启动。按源码调试时，修改仓库不会自动更新另外一份 MFA；同步方式见 [打包与开发说明](release.md)。

**资源加载失败？**

确认使用完整解压的 Windows ZIP，并从 `Start MaaUma.cmd` 启动。若是手动部署源码，请检查运行目录的 `resource/model/ocr/` 是否同时包含 `det.onnx`、`rec.onnx` 和 `keys.txt`。

**角色下拉框输入中文后不筛选？**

MFA v2.15.2 的该问题已有版本限定的本地兼容补丁，安装与恢复方法见 [下拉框搜索修复](mfa-dropdown-search-fix.md)。便携包保留原版前端，补丁可按需安装；其他前端版本需另行确认。

**任务卡住或识别失败？**

保留 MFA 导出的日志压缩包和失败时的截图，同时记录任务名称与最后一个步骤。Agent 的辅助日志位于运行目录的 `debug/maauma-agent.log`。

当前流程主要适配上述游戏版本和画面布局。奖励为空、购买确认后的额外提示以及尚未提供规则的新弹窗，仍可能需要补充处理；“限时售卖购买”目前执行到点击“确定”，尚未增加购买结果校验。启动流程的个别备用规则与通用返回／关闭模板仍有占位，详见资源适配记录。
